Section 01

主題簡介：Claude Skill

Claude 的 Skill（技能）功能讓使用者把專業知識打包成可重複使用的指令集。每個 Skill 是一個資料夾，包含說明檔與相關資源，Claude 會在偵測到相關任務時自動載入。

這項設計避免了重複貼上長提示，也讓團隊能共享最佳實踐，是打造一致 AI 工作流程的關鍵工具。

Section 02

Three-Level English Passages

Anyone who's spent serious time prompting Claude eventually runs into the same wall: you keep pasting the same instructions over and over. Skills are Anthropic's answer to that. Essentially, a Skill is a folder bundling a SKILL.md file with whatever scripts or references Claude needs, and the model loads it on demand whenever a task matches. Rather than cramming everything into one bloated system prompt, you let Claude pull in expertise only when it's relevant. This unlocks consistent workflows across teams, version-controlled know-how, and dramatically leaner context windows. It's a remarkably elegant fix for a problem most power users had quietly resigned themselves to.

Key Corrections

  • Subject–verb agreement under a long relative clause: Anyone who uses Claude a lot run → Anyone who uses Claude a lot runs (the subject is Anyone, third-person singular; the intervening who-clause can pull the ear toward the wrong verb)
  • Countability of instruction: the same instruction over and over → the same instructions over and over (countable in this sense — a set of directions)
  • Missing noun head + wrong preposition: a skill is bundling with a Skill.md file → a Skill is a folder bundling a SKILL.md file (definition needs the noun a folder; bundling X means containing X, while bundling with X means packaged alongside X)
  • Typo: scrips → scripts
  • Verb complement of help: This helps consistent workflow → This supports consistent workflows (help needs an infinitive, a person/thing object, or a switch to supports; also workflow should be plural across teams)
  • Uncountable noun: shared know-how's → shared know-how (no plural, no apostrophe-s — same shape as advice or information)
  • Word coinage + dangling pronoun: a problem some power users often quietly aspected it → a problem most power users had quietly resigned themselves to (aspected is not a word; the relative-clause structure also can't carry a dangling object pronoun referring back to a problem)
Level: B2+ reaching toward C1
